# 🧠 MacroPolo

**A lightweight, scriptable desktop automation tool powered by Lua and Rust.**

Control your mouse, keyboard, and scripts with full precision using simple Lua scripts. Useful for productivity automation, game macros, testing, or accessibility enhancements.

---

## ✨ Features

- ✅ Mouse and keyboard simulation
- ✅ Lua scripting engine with native Rust function bindings
- ✅ Simple GUI to load, run, and manage scripts
- ✅ Hotkey support to trigger macros
- ✅ Extendable: easily add custom logic or features
